## 🛠️ Installation & Best Practices 
> [!TIP] 
> **Recommended Database Naming:** For optimal compatibility, it is **highly recommended** to name your Odoo database **`data1`**. 
 
## 📊 Power BI Usage Guide 
Paste your URL in Power BI and select **Anonymous** authentication.
